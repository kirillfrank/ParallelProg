## Описание

Вычисление скалярного произведения двух векторов `a` и `b` одинаковой длины `n` (последовательная версия).

## Метод

Скалярное произведение:

```
dot = a₁·b₁ + a₂·b₂ + … + aₙ·bₙ
```

Сложность — `O(n)`. Основной цикл `Σ aᵢ·bᵢ` будет распараллелен в лабораторной работе №2 (OpenMP).

## Файлы

- `dot_product.cpp` — последовательная реализация
- `generate_data.py` — генератор тестовых векторов
- `verify.py` — верификация через `numpy.dot`
- `benchmark.py` — автоматизация серии экспериментов
- `Makefile` — сборка

## Сборка

```bash
make
```

## Быстрый старт

```bash
# 1. Сгенерировать тестовые данные (n = 1 000 000)
python3 generate_data.py 1000000 input.txt

# 2. Запустить решатель
./dot_product input.txt output.txt

# 3. Верифицировать результат
python3 verify.py input.txt output.txt
```

**Ожидаемый вывод верификации:**
```
Computed  : ...
Reference : ...
Relative error: 0.000e+00
VERIFICATION: OK
```
