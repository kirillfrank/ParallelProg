\# ParallelProg-2026



Лабораторные работы по параллельному программированию.



Подробности и результаты каждой лабораторной приведены в её

собственном отчёте:



\- \[Лабораторная работа 1](lab1/REPORT.md) — последовательная версия

&#x20; скалярного произведения векторов. \[Инструкция по сборке](lab1/README.md)

\- Лабораторная работа 2 — параллельная версия на OpenMP. \*(в разработке)\*



\## О чём репозиторий



Необходимо распараллелить вычислительную задачу с использованием

открытых стандартов параллельного программирования на языке C/C++.

Для этого нужно провести серию тестирований: в первой лабораторной

работе — последовательно, во второй — с помощью OpenMP, далее — с

использованием других технологий (MPI и т.д.).



Тема распараллеливания — \*\*скалярное произведение двух векторов\*\*.

Каждая новая лабораторная берёт за основу решатель из предыдущей

и переносит основной вычислительный цикл (`Σ aᵢ·bᵢ`) на новую

технологию — меняется только способ и скорость вычисления, но не

сам алгоритм и не формат входных/выходных данных.



Все версии решателя на одних и тех же входных данных обязаны

находить одно и то же решение (с точностью до `eps`) — сравнивается

только время работы.



\## Методика эксперимента



Для каждого размера задачи `n` генерируются два случайных вектора

(`generate\_data.py`), решатель запускается через `benchmark.py`,

результаты попадают в `results.csv` соответствующей лабораторной.



\### Замер



Секундомер (`std::chrono::high\_resolution\_clock`) включается

непосредственно перед циклом вычисления скалярного произведения

и выключается сразу после него. Чтение входного файла и запись

результата в замер не входят.



\### Верификация



После каждого запуска результат сверяется скриптом `verify.py` с

эталоном `numpy.dot` (BLAS). Критерий прохождения — относительная

ошибка меньше `1e-4`.



\## Требования



\- Компилятор C++ (GCC / Clang), поддержка C++17;

\- `make`;

\- Python 3.10+, пакеты `numpy`, `matplotlib`.



\## Быстрый старт (на примере лабораторной работы 1)



```bash

cd lab1

make

python3 generate\_data.py 1000000 input.txt

./dot\_product input.txt output.txt

python3 verify.py input.txt output.txt

```
