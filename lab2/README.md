## 📋 Описание

Параллельная реализация скалярного произведения двух векторов
с использованием технологии **OpenMP**. Проведена серия экспериментов
с разным числом потоков и размеров векторов.

## 🖥 Конфигурация системы

- **ОС:** Ubuntu 24.04 LTS (WSL2, Windows 11)
- **Компилятор:** GCC 15.2.0
- **Флаги:** `-O2 -std=c++17 -fopenmp`
- **Тип данных:** `double`
- **Ядер:** 8

## 🧪 Методика эксперимента

- **Размеры векторов:** 1M, 2M, 4M, 8M, 16M, 32M
- **Число потоков:** 1, 2, 4, 6, 8
- **Повторов:** 5 (берётся минимум времени)
- **Замер:** `omp_get_wtime()` вокруг основного цикла
- **Производительность:** `GFLOPS = 2·n / (time_s · 10⁹)`

## 🛠 Сборка

```bash
make
```

## 🚀 Быстрый старт

```bash
# 1. Сгенерировать тестовые данные (n = 4 000 000)
python3 generate_data.py 4000000 input.txt

# 2. Запустить решатель в 4 потока
./dot_product_omp input.txt output.txt 4

# 3. Верифицировать результат
python3 verify.py input.txt output.txt
```

**Ожидаемый вывод верификации:**
