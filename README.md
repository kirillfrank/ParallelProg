# Parallel-programming

Лабораторные работы по параллельному программированию.

Подробности и результаты конкретной лабораторной работы приведены в её собственном отчёте:

- [Лабораторная работа 1](lab1/REPORT.md) — последовательная версия. [Инструкция](lab1/README.md)
- [Лабораторная работа 2](lab2/REPORT.md) — параллельная версия на OpenMP. [Инструкция](lab2/README.md)

## Задание л/р

**1.** Написать программу на языке C/C++ для вычисления скалярного произведения двух векторов. Исходные данные: файл(ы), содержащие значения исходных векторов. Выходные данные: файл со значением скалярного произведения, время выполнения, объём задачи и др. Обязательна автоматизированная верификация результатов вычислений с помощью сторонних библиотек или стороннего ПО (например, на Matlab/Python).

**2.** Модифицировать программу из л/р №1 для параллельной работы по технологии OpenMP. Провести серию экспериментов с разным количеством потоков (1, 2, 4, 6, 8), разными размерами векторов (1M, 2M, 4M, 8M, 16M, 32M), с разным количеством вычислительных ядер.

## Требования

- Компилятор C++ (GCC / Clang), поддержка C++17
- `make`
- OpenMP
- Python 3.10+ с пакетами `numpy`, `matplotlib`

## Быстрый старт (на примере лабораторной работы 1)

```bash
cd lab1
make
python3 generate_data.py 1000000 input.txt
./dot_product input.txt output.txt

```
