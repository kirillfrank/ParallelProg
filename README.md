\## Описание



Параллельная реализация скалярного произведения двух векторов

с использованием технологии \*\*OpenMP\*\*. Проведена серия экспериментов

с разным числом потоков и размеров векторов.



\## Конфигурация системы



\- \*\*ОС:\*\* Ubuntu 24.04 LTS (WSL2, Windows 11)

\- \*\*Компилятор:\*\* GCC 15.2.0

\- \*\*Флаги:\*\* `-O2 -std=c++17 -fopenmp`

\- \*\*Тип данных:\*\* `double`



\## Методика эксперимента



\- Размеры векторов: 1M, 2M, 4M, 8M, 16M, 32M

\- Число потоков: 1, 2, 4, 6, 8, 12

\- Каждая точка — минимум из 5 запусков (усреднение от шума)

\- Замер через `omp\_get\_wtime()`



\## Сборка



```bash

make

```



\## Быстрый старт



```bash

\# 1. Сгенерировать данные

python3 generate\_data.py 4000000 input.txt



\# 2. Запустить в 4 потока

./dot\_product\_omp input.txt output.txt 4



\# 3. Верифицировать

python3 verify.py input.txt output.txt

```



\## Полный эксперимент



```bash

python3 benchmark\_omp.py

python3 plot\_omp.py

```



Результаты: `results.csv`, `time.png`, `speedup.png`, `gflops.png`.
