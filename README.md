## О чём репозиторий

Необходимо распараллелить вычислительную задачу с использованием открытых стандартов параллельного программирования на языке C/C++. Для этого нужно провести серию тестирований: в первой лабораторной работе — последовательно, во второй — с помощью стандарта OpenMP, далее — с использованием других технологий параллельного программирования (MPI и т.д.).

**Тема распараллеливания** — вычисление скалярного произведения двух векторов `a` и `b`. Каждая новая лабораторная берёт за основу решатель из предыдущей и переносит основной вычислительный цикл (сумма `Σ aᵢ·bᵢ`) на новую технологию — меняется только способ и скорость вычисления, а не сам алгоритм и не формат входных/выходных данных.

Все версии решателя на одних и тех же входных данных обязаны находить одно и то же решение (с точностью до `eps`) — сравнивается только время работы.

## Методика эксперимента

Для каждого размера задачи `n` генерируются два случайных вектора (`generate_data.py`), решатель запускается через `benchmark.py`, результаты попадают в `results.csv` соответствующей лабораторной работы.

### Замер

Секундомер (`std::chrono::high_resolution_clock`) включается непосредственно перед основным циклом вычисления скалярного произведения и выключается сразу после его завершения. Чтение входного файла и запись результата в замер не входят.

### Верификация

После каждого запуска результат сверяется скриптом `verify.py` с эталоном, полученным через `numpy.dot` (BLAS). Критерий прохождения — относительная ошибка меньше `1e-4`.

## Требования

- Компилятор C++ (GCC/Clang), поддержка C++17;
- `make`;
- Python 3.10+, пакеты `numpy`, `matplotlib`.

## Быстрый старт (на примере лабораторной работы 1)

```bash
cd lab1
make
python3 generate_data.py 1000000 input.txt
./dot_product input.txt output.txt
python3 verify.py input.txt output.txt
```
